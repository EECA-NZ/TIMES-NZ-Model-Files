This folder contains historical data for several high-level metrics.
These are used to compare model performance for base and historical model years to empirical results, 
which will help us calibrate results correctly. 

Note: the data has been manually collated.

These should include: 

Total generation
Generation per tech type 

Electricity generation for 2023-2025 is pulled from MBIE quarterly data as at April 2026



Total energy demand 
Energy demand per sector and fuel 


Emissions (per sector)
Currently, we focus just on 2023-2025 results.
