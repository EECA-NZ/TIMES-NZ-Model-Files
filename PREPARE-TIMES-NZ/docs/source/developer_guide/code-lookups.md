# Code lookups 

This page acts as a reference for individual process and commodity codes used in the model.

These files are updated when model post-processing runs. 

**Process code lookups:**

 - {download}`Demand devices<data/processes/demand.csv>`
 - {download}`Electricity generation<data/processes/elec_generation.csv>`
 - {download}`Batteries<data/processes/batteries.csv>`

**Commodity code lookups:**
 - {download}`Energy commodities<data/commodities/energy.csv>`
 - {download}`Demand commodities<data/commodities/demand.csv>`


These cover the vast majority of use cases, but exclude some smaller lookup tables such as currency or emission codes. For the complete list of sets, you can browse the files at `TIMES-NZ-INTERNAL-QA/data/concordances`, and add these here if they're commonly required.
